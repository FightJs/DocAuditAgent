# DocAuditAgent 前端设计规格

## 目标

在 `frontend/` 建立桌面优先、响应式的 Web 单页应用，按 Pencil 设计稿实现 P1-P7，并以 Mock HTTP 接口完成可交互的案件审核流程。当前工作区不包含可用于联调的后端源码，本次不改动后端或加入真实凭据。

## 输入

- Pencil 文件：`/Users/xiaochao/.pencil/documents/03e30027-5a91-4599-80c8-6a93d7bc6f86/pencil-new.pen`
- 页面设计：P1 案件列表、P2 新建与上传、P3 案件详情、P4 补件、P5 风险证据、P6 人工审核、P7 决定确认与交付预览。
- 业务/API 依据：`docs/08_api_spec/api_spec-v1.0.md` 与 `docs/06_system_architecture/frontend_design_spec-v1.0.md`。

## 页面与路由

| 页面 | 路由 | 核心目标 |
| --- | --- | --- |
| P1 | `/cases` | 筛选、检索并打开授权案件；进入新建或审核待办。 |
| P2 | `/cases/new` | 创建案件、选择材料、上传并提交。 |
| P3 | `/cases/:caseId` | 查看当前版本、运行、责任、材料与时间线。 |
| P4 | `/cases/:caseId/materials` | 根据补件请求创建并提交新版本。 |
| P5 | `/cases/:caseId/evidence` | 查看风险项、原文摘录和可见依据。 |
| P6 | `/review` | 接收审核待办，查看当前案件与可处置风险。 |
| P7 | `/review/confirm` | 校验决定上下文、理由与交付预览。 |

## 架构

- 使用 React、TypeScript、Vite 和 React Router 构建单页应用。
- 页面组件只通过 `src/api/` 访问服务；请求和响应使用现有 `/api/v1` 契约的字段形状。
- 使用 MSW 在浏览器中拦截 `/api/v1/*`。`src/mocks/` 持有案例数据、处理器和可变内存状态。
- Mock 与页面解耦：关闭 Mock 启动后，`src/api/` 可直接连接真实后端，无需修改页面业务逻辑。
- 共享 UI 包含顶栏、页面标题区、上下文摘要、状态徽标、通知条、内容面板、表单字段与错误提示。

## Mock 行为

Mock 覆盖案件查询与筛选、创建案件、上传批次创建、文件内容接收、批次提交、补件的新版本创建、风险与证据查询、待办接收和人工决定提交。

状态变更保留版本与并发含义：补件创建新的 `document_version_id`；人工决定要求 `expected_revision`、理由与当前上下文；冲突返回 `revision_conflict`，权限不足返回可展示的授权错误。所有演示数据清楚标识为 Mock，不表示真实审核结论。

## 交互与可见性

- P1 的筛选与搜索即时作用于 Mock 列表；桌面使用表格，移动端显示案件摘要卡片。
- P2/P4 具有字段校验、文件选择、上传进度与提交反馈；成功后转入 P3。
- P3 按 `allowed_actions` 显示补件、证据或审核入口；不以跳转替代状态变更。
- P5 选择风险项后更新证据面板。证据不足显示“待人工确认”。
- P6 必须先接收待办，才展示决定动作；P7 展示当前版本、运行、基线与理由，并在提交时处理冲突和错误。
- 实现加载、空数据、无权限、网络失败和操作中状态。前端不推断授权、不生成风险结论、不展示内部轨迹。

## 视觉与响应式

遵循 Pencil 的业务工作台视觉：浅灰页面背景、白色边框面板、深蓝主要操作、青绿色链接与信息状态，以及压缩但可扫描的文字层级。桌面保留设计稿中的双栏和三栏关系；小于 768px 时改为单列，表格变为摘要卡片。按钮、表单、状态和导航具有键盘焦点与可见标签，状态不只依赖颜色传达。

## 验证

1. 为 Mock 状态变更与核心状态映射编写单元测试。
2. 覆盖创建案件、提交材料、补件、风险切换、接收待办和确认决定的交互测试。
3. 在桌面和移动视口进行浏览器验证，检查布局、文字溢出、键盘可达性和路由跳转。
4. 运行 TypeScript 检查、测试与生产构建。

## 风险与回滚

- 真正的后端契约可能与当前文档不同。风险通过集中 API 客户端与 MSW 处理器隔离；接入时由契约测试校验。
- Mock 内存状态刷新后重置，仅用于本地演示。不得被用于审批、文件存储或生产数据。
- 所有新增前端文件限定在 `frontend/`。移除 `src/mocks/` 的启动入口可回退为真实 API 模式，不影响路由和组件结构。
